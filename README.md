# INTERNO School — лендинг открытого урока «Архитектура»

Одностраничный лендинг бесплатного открытого урока по архитектуре
(Ташкент · Самарканд · Фергана). Продолжает визуальный язык остальных
лендингов школы (Unbounded + Inter, фирменный оранжевый `#F76B2B`,
liquid-glass стекломорфизм), но в собственной «чертёжной» айдентике:
тёмный графитовый лист, сетка миллиметровки, размерные линии.

## Структура

| Файл | Назначение |
| --- | --- |
| `index.html` | Лендинг: разметка + инлайновый i18n-словарь (RU/UZ) и boot-скрипт |
| `styles.css` | Дизайн-система: blueprint-тема, liquid-glass, адаптив |
| `script.js` | Параллакс, scroll-reveal, счётчики, квиз, каунтдаун, формы (amoCRM + Telegram), Meta Pixel-события, ленивый 3D-вьюер |
| `thanks.html` | Страница после заявки (CompleteRegistration + advanced matching) |
| `api/notify.js` | Vercel serverless: уведомление о лиде в Telegram (env: `TG_BOT_TOKEN`, `TG_CHAT_ID`, опц. `TG_TOPIC_ID`) |
| `assets/download.sh` | Скачивает все сгенерированные ассеты с CDN для self-host |

## Контент-фичи

- **RU/UZ локализация** — синхронно до первой отрисовки (`?lang=uz|ru`), город — `?city=tsh|smr|fer`.
- **Еженедельный цикл урока** — дата, каунтдаун и «осталось N мест» считаются от якорной даты (`LESSON_SCHEDULE` в `index.html`), страница не устаревает.
- **Квиз из 5 вопросов** с вердиктом и мини-формой (лучший лид-магнит по опыту interno-open-lesson).
- **Заявки**: amoCRM (единая форма школы, тег «Архитектура») + Telegram-уведомление + Meta Pixel `Lead`/`CompleteRegistration` с дедупликацией по eventID, UTM-сквозняк.

## Визуал (сгенерирован в Higgsfield)

Hero-диорама дома, «спутники» (рулон чертежей, циркуль, каска, макет),
3D-иконки секций, 6 рендеров «работ студентов», портрет спикера,
видео-анимация «из чертежа в здание» (Seedance) и интерактивная
**3D-модель дома (GLB, image-to-3d)** — подгружается по клику через
`<model-viewer>`.

Ассеты подключены с CDN Higgsfield (как Unsplash-фото в
`interno-open-lesson`). Для self-host: `bash assets/download.sh` и
замените CDN-префикс в `index.html` на `assets/`.

## Перед запуском в прод — заменить плейсхолдеры

- **Спикер**: имя «Тимур Рахимов», регалии и портрет — сгенерированные
  заглушки. Подставьте реального ментора курса (фото, цифры, Instagram).
- **Работы студентов** — AI-рендеры-заглушки; заменить на реальные
  проекты, когда появятся первые выпуски.
- Даты урока (`LESSON_SCHEDULE`), Telegram-канал в `thanks.html`,
  ссылки соцсетей в футере.
- ID пикселя и amoCRM-форма взяты с действующего лендинга школы —
  проверить, что поток «Архитектура» размечается в CRM корректно.
